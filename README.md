# Nauntanki Ghar — Android app

Download the latest APK from the **Releases** page: https://github.com/HeetShukla/nauntanki-ghar-app/releases/latest

Install: open the downloaded file on your Android phone → allow "Install unknown apps" once → install.
First run: Settings → AI → paste a free Groq API key. Then the app plans your day's Instagram content; you approve, it posts.

Everything runs on the phone. No server, no laptop.
